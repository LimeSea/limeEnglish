limeEnglish 是一款帮助中文用户在真实语境中理解英文单词的 Chrome 扩展。

在网页中双击英文单词，limeEnglish 会结合当前句子和附近文本分析词义，并在原位置展示 IPA 音标、中文语境义、相关短语、整句翻译与语法解析。词卡关闭后即可继续阅读，不需要切换到词典页面。

遇到过的单词会自动保存到本地词汇库，并记录出现次数、来源和历史语境。词汇库支持搜索、排序、分页和详情查看，方便回顾同一个单词在不同文章中的实际用法。
